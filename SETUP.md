# Как поставить Пульс себе

Пульс — личный экран на одном компьютере: дела из Obsidian, новости по вашим темам и чаты Telegram. Он работает только у вас на компьютере и ничего не выкладывает в интернет. Установка займёт минут двадцать.

## Что понадобится

- Windows 10 или 11.
- **Python 3.12** с [python.org](https://www.python.org/downloads/). При установке отметьте галочку **Add python.exe to PATH**, иначе ничего не запустится.
- **Git** с [git-scm.com](https://git-scm.com/download/win), чтобы скачать проект и потом получать обновления. Можно обойтись без него, см. шаг 1.
- Аккаунт Telegram.
- По желанию: [Obsidian](https://obsidian.md) с хранилищем заметок. Без него не будет раздела «Дела», остальное работает.
- По желанию: подписка Claude и [приложение Claude](https://claude.ai/download) или Claude Code. Без них не будет саммари от Claude и вопросов к нему, остальное работает.

## 1. Скачать проект

Откройте командную строку в папке, где хотите держать Пульс, и выполните:

```bash
git clone https://github.com/beautiful-cookie/pulse.git
cd pulse
```

Без Git: на странице проекта нажмите **Code → Download ZIP** и распакуйте архив. Обновлять тогда придётся так же, вручную.

## 2. Поставить библиотеки

Двойной щелчок по `install.bat`. Он поставит четыре библиотеки из `requirements.txt`.

## 3. Подключить Telegram

1. Откройте [my.telegram.org](https://my.telegram.org), войдите по номеру телефона, зайдите в **API development tools** и создайте приложение. Название и адрес любые. Понадобятся два значения: `api_id` и `api_hash`.
2. Запустите `telegram_login.bat`, вставьте `api_id` и `api_hash` (правая кнопка мыши или Ctrl+V) и нажмите Enter.
3. Откроется браузер с QR-кодом. В Telegram на телефоне: **Настройки → Устройства → Подключить устройство**, отсканируйте код. Если стоит облачный пароль, наберите его в окне вручную.

Пульс только читает Telegram: в коде нет отправки, редактирования и удаления, сообщения остаются непрочитанными. Файл `data/telegram.session` равносилен входу в ваш аккаунт. Никому его не пересылайте. Отключить Пульс можно в Telegram: **Настройки → Устройства**.

## 4. Первый запуск

Двойной щелчок по `start.bat`. Откроется браузер с адресом `http://127.0.0.1:8765`. Окно с чёрным экраном не закрывайте: это и есть Пульс.

В **Настройках**:

- **Чаты Telegram**: отметьте чаты, которые Пульс может читать. Есть флажок «Выбрать все чаты». Нажмите **Сохранить** внизу.
- **Темы**: замените темы-примеры на свои. По ним отбираются новости.
- **Обновление и уведомления**: можно включить запуск вместе с Windows, тогда окно не нужно.

## 5. Указать свои имя и хранилище Obsidian

Эти настройки пока меняются только в файле. Закройте окно Пульса, откройте `config.json` в Блокноте и поправьте:

```json
"vault": "C:\\Users\\Имя\\Documents\\Obsidian Vault",
"me": {"names": ["Имя", "Фамилия"]},
```

- `vault` — папка вашего хранилища Obsidian. Каждую обратную косую черту пишите дважды.
- `me.names` — как вас называют в чатах. По этим словам Пульс замечает, что к вам обращаются.
- В разделе `obsidian` поле `agenda_notes` — заметка, куда Пульс пишет дела. По умолчанию это `00 Система/Инбокс/Актуальное.md`. Можно указать свою, например `["Задачи.md"]`. Если заметки нет, Пульс создаст её с первой задачей. В другие заметки он не пишет никогда.

Сохраните файл и снова запустите `start.bat`.

## 6. Локальная модель (по желанию)

Модель на вашем компьютере пересказывает чаты, находит дела и сроки, делает саммари статей. Без неё Пульс работает на правилах, просто проще. Чтобы поставить:

```bash
python -m pulse install-model
```

Скачается около 3 ГБ: сервер llama.cpp и модель Gemma. Во время работы она занимает около 4 ГБ памяти. Проверить качество можно файлом `model_check.bat`.

## 7. Claude (по желанию)

Нужны подписка Claude и установленное приложение Claude или Claude Code. Запустите `claude_login.bat`: откроется браузер, Claude выдаст токен на год, вставьте его в окно. Claude получает только публичные материалы: новости, посты каналов и открытые группы. Закрытые группы и личные переписки к нему не уходят.

## Телефон

**Настройки → Телефон**: включите доступ и отсканируйте QR-код. Телефон и компьютер должны быть в одной сети Wi-Fi. Компьютер при этом должен быть включён, а Пульс запущен. В общественном Wi-Fi доступ лучше выключать: соединение не шифруется.

## Обновления

```bash
git pull
```

Затем перезапустите `start.bat`. Ваши настройки и данные лежат в `config.json` и `data/`, обновление их не трогает.

## Что не попадает в Git

`config.json`, `data/` (база, сессия Telegram, токен Claude), `models/` и `tools/` перечислены в `.gitignore`. Если вы сделаете свой форк и будете в него коммитить, не добавляйте их принудительно (`git add -f`): там ваши чаты и вход в Telegram.

## Можно ли залить Пульс на Firebase

Нет, и это сделано намеренно.

- **Firebase Hosting раздаёт только готовые файлы** — HTML, стили, скрипты. А Пульсу нужен работающий сервер на Python. Каждые пять минут он читает Telegram, хранит базу, пишет дела в Obsidian и запускает локальную модель. На Hosting такой сервер не запустить.
- **Перенести сервер в облако Google** (Cloud Run или Cloud Functions за тем же Firebase) технически можно, но тогда:
  - на чужих серверах окажутся сессия Telegram (то есть полный вход в ваш аккаунт) и тексты всех чатов;
  - Obsidian и локальная модель там недоступны, их пришлось бы переписывать;
  - база в Cloud Run стирается при каждом перезапуске, нужна была бы отдельная облачная база.
- **Главная идея Пульса** — чаты читаются и хранятся только на вашем компьютере. Облачная версия её отменяет.

Чтобы открывать Пульс не только с компьютера, используйте раздел «Телефон» выше. Если очень хочется что-то выложить на Firebase, подойдёт только страница с описанием проекта и ссылкой на GitHub. Сам Пульс там работать не будет.

## Если что-то не так

- Запустите `python -m pulse doctor`: он проверит Telegram, Obsidian, модель и Claude и подскажет, что не настроено.
- «python не является внутренней или внешней командой» — Python поставлен без галочки PATH. Переустановите его с галочкой.
- Подробнее о том, как всё устроено, написано в [README.md](README.md).
