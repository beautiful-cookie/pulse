# Пульс: установка для тех, кто не программирует

Эта инструкция — для тех, кто никогда не ставил программы «из кода». Ничего страшного здесь нет. Нужно скачать три вещи, несколько раз дважды щёлкнуть по файлам и один раз войти в Telegram. Займёт это примерно полчаса, большую часть времени вы будете ждать загрузку.

**Что такое Пульс.** Это страничка в браузере, на которой собрано всё важное за день:
- ваши дела и сроки;
- сообщения из Telegram, где от вас чего-то ждут;
- новости по темам, которые вы выберете.

Пульс работает только на вашем компьютере. Ваши переписки никуда не отправляются и нигде, кроме вашего компьютера, не хранятся.

**Что нужно:**
- компьютер с Windows 10 или 11;
- интернет;
- телефон с Telegram.

---

## Шаг 1. Установить Python

Python — это программа, на которой работает Пульс. Её достаточно установить один раз.

1. Откройте [страницу загрузки Python для Windows](https://www.python.org/downloads/windows/).
2. Найдите в списке самую новую версию **Python 3.12**, под которой есть ссылка **Download Windows installer (64-bit)**. Сейчас это 3.12.10. Нажмите эту ссылку. Скачается файл вроде `python-3.12.10-amd64.exe`.
3. Откройте скачанный файл.
4. ⚠️ **Самое важное во всей инструкции:** в самом низу первого окна поставьте галочку **Add python.exe to PATH**. Без неё ничего не заработает.
5. Нажмите **Install Now** и дождитесь конца установки.
6. Если в конце будет кнопка **Disable path length limit**, нажмите её. Если нет, ничего страшного. Нажмите **Close**.

## Шаг 2. Скачать Пульс

1. Нажмите на ссылку: **[скачать Пульс (ZIP-архив)](https://github.com/beautiful-cookie/pulse/archive/refs/heads/main.zip)**. Скачается файл `pulse-main.zip`.
2. Откройте папку **Загрузки**, щёлкните по `pulse-main.zip` правой кнопкой мыши и выберите **Извлечь все…**.
3. В окне нажмите **Обзор…**, выберите папку **Документы** и нажмите **Извлечь**.
4. В Документах появится папка `pulse-main`. Это и есть Пульс. Дальше в инструкции она называется **папкой Пульса**.

> Запускайте файлы только из распакованной папки, а не прямо из архива. Иначе Пульс не сможет ничего сохранить.

Внутри папки лежат файлы с шестерёнкой на значке: `install`, `start`, `telegram_login` и другие. Так Windows показывает файлы запуска. Открываются они двойным щелчком.

**Если Windows спрашивает, можно ли запустить файл:**
- Синее окно «Windows защитила ваш компьютер»: нажмите **Подробнее**, затем **Выполнить в любом случае**.
- Окно «Предупреждение системы безопасности»: нажмите **Запустить**.

Windows так реагирует на любой файл, скачанный из интернета, а не только на Пульс.

## Шаг 3. Поставить дополнения

Дважды щёлкните по файлу **`install`** в папке Пульса. Откроется чёрное окно, по нему побегут строчки. Через минуту появится надпись «Готово». Нажмите любую клавишу, и окно закроется.

Если окно пишет по-английски **Python not found**, вернитесь к шагу 1: скорее всего, при установке Python не была отмечена галочка PATH. Откройте установщик Python ещё раз и переустановите его с галочкой. Если написано «Не получилось», проверьте интернет и запустите `install` ещё раз.

## Шаг 4. Получить ключи Telegram

Пульсу нужно разрешение читать ваш Telegram. Для этого Telegram выдаёт два ключа. Их получают один раз.

1. Откройте [my.telegram.org](https://my.telegram.org).
2. Введите свой номер телефона с кодом страны, например `+79991234567`, и нажмите **Next**.
3. Код придёт **в приложение Telegram**, в чат от «Telegram», а не по SMS. Введите его на сайте и нажмите **Sign In**.
4. Нажмите **API development tools**.
5. Заполните форму:
   - **App title** — любое название, например `Pulse`;
   - **Short name** — латинские буквы без пробелов, от 5 символов, например `mypulse`;
   - **URL** — оставьте пустым;
   - **Platform** — выберите **Desktop**;
   - **Description** — можно оставить пустым.
6. Нажмите **Create application**.
7. Откроется страница с ключами. Понадобятся два значения:
   - **App api_id** — число, например `1234567`;
   - **App api_hash** — длинная строка из букв и цифр.

   Не закрывайте эту страницу.

Если сайт пишет **ERROR**, выключите VPN, если он включён, или откройте сайт в другом браузере. Это частая и безобидная ошибка самого сайта Telegram.

Никому не показывайте эти ключи и не отправляйте их в чаты.

## Шаг 5. Подключить Telegram

1. Дважды щёлкните по файлу **`telegram_login`** в папке Пульса. Откроется чёрное окно.
2. Окно попросит `api_id`. Скопируйте число со страницы my.telegram.org. Чтобы вставить его в чёрное окно, щёлкните в окне **правой кнопкой мыши** или нажмите **Ctrl+V**. Нажмите **Enter**.
3. Так же вставьте `api_hash` и нажмите **Enter**.
4. Окно спросит способ входа. Просто нажмите **Enter**: это вход по QR-коду.
5. В браузере откроется QR-код. На телефоне откройте Telegram: **Настройки → Устройства → Подключить устройство** и наведите камеру на код.
6. Если у вас в Telegram стоит облачный пароль, окно попросит его. Вводите пароль вслепую: символы не видны, так и задумано. Нажмите **Enter**.
7. Появится надпись «Вход выполнен» и «Готово». Окно можно закрыть.

**Это безопасно.** Пульс только читает. Он не умеет отправлять, удалять и менять сообщения и не помечает их прочитанными. В списке устройств Telegram он будет виден как новое устройство. Отключить его можно там же: **Настройки → Устройства** → нажмите на него → **Завершить сеанс**.

## Шаг 6. Запустить Пульс

1. Дважды щёлкните по файлу **`start`**.
2. Откроется чёрное окно, а через пару секунд и браузер со страницей Пульса. **Чёрное окно не закрывайте**: пока оно открыто, Пульс работает. Его можно свернуть.
3. Если браузер не открылся сам, откройте его и введите адрес **http://127.0.0.1:8765**. Добавьте страницу в закладки.

## Шаг 7. Настроить под себя

Нажмите **Настройки** в меню слева. Это колонка значков на компьютере или строка внизу на телефоне. Разделы раскрываются щелчком по названию. После изменений **обязательно нажмите синюю кнопку «Сохранить» внизу**.

1. **Чаты Telegram.** Отметьте галочками чаты, которые Пульс может читать: учёбу, работу, друзей. Чаты сгруппированы по вашим папкам из Telegram. Если список пустой, нажмите **Обновить список**. Можно отметить всё сразу флажком **Выбрать все чаты**.
2. **Темы.** Здесь стоят темы-примеры. Замените их своими, например «Дизайн» или «Кино», и впишите слова, по которым искать новости. Ненужные темы удалите.
3. **Отбор → Как вас называют в чатах.** Впишите через запятую, как к вам обращаются, например `Аня, Анна, Смирнова`. По этим словам Пульс замечает, что вас зовут в группе.
4. **Obsidian и дела.** Здесь указано, где хранить ваши дела. Этот пункт описан ниже.
5. **Обновление и уведомления → Запускать Пульс при входе в Windows.** С этой галочкой Пульс будет включаться сам вместе с компьютером, без чёрного окна.

Первый сбор чатов и новостей займёт несколько минут. Потом вернитесь на страницу **Сегодня** и нажмите круглую стрелку справа вверху, если ничего не появилось.

### Где хранятся дела

Раздел **Дела** — доска с карточками: «Сделать», «В работе», «Жду», «Готово». Дела записываются в обычный текстовый файл.

- **Если вы пользуетесь [Obsidian](https://obsidian.md)** (это приложение для заметок): в **Настройки → Obsidian и дела** вставьте адрес папки вашего хранилища. Чтобы его узнать:
  1. откройте папку хранилища в Проводнике;
  2. щёлкните по адресной строке сверху;
  3. скопируйте адрес вроде `C:\Users\Аня\Documents\Заметки`.

  В поле **Заметка для дел** напишите, в какую заметку складывать дела, например `Задачи.md`. Пульс пишет только в эту заметку, остальные лишь читает.
- **Если Obsidian у вас нет**, ничего не меняйте. Пульс сам создаст папку `Obsidian Vault` в Документах и будет хранить дела там. Если когда-нибудь поставите Obsidian, откройте эту папку как хранилище, и все дела окажутся на месте.

## Шаг 8 (по желанию). Умная модель на компьютере

Без модели Пульс работает по правилам. С моделью он умнее:
- пересказывает, о чём говорили в чатах;
- находит дела и сроки в сообщениях;
- делает короткие пересказы статей.

Модель работает прямо на вашем компьютере, без интернета, поэтому переписки по-прежнему никуда не уходят.

**Что нужно:** около 4 ГБ свободного места на диске. Желательно 8 ГБ оперативной памяти или больше: во время работы модель занимает около 4 ГБ.

**Как поставить, способ попроще:**
1. Дважды щёлкните по файлу **`install_model`** в папке Пульса.
2. Начнётся загрузка, около 3 ГБ. В окне видны проценты. Это может занять от 5 минут до часа.
3. Если загрузка прервалась, запустите файл ещё раз: она продолжится с того же места.
4. Когда появится «Модель на месте», закройте чёрное окно Пульса и снова откройте `start`.

**Если способ попроще не сработал, можно вручную:**
1. Скачайте программу для запуска модели, архив llama.cpp: **[llama-b12048-bin-win-cpu-x64.zip](https://github.com/ggml-org/llama.cpp/releases/download/b12048/llama-b12048-bin-win-cpu-x64.zip)**.
2. В папке Пульса создайте папку `tools`, а в ней папку `llama`. Должно получиться `pulse-main\tools\llama`.
3. Откройте скачанный архив двойным щелчком, выделите всё внутри (**Ctrl+A**), скопируйте (**Ctrl+C**) и вставьте (**Ctrl+V**) в папку `tools\llama`. Внутри должен оказаться файл `llama-server`.
4. Скачайте саму модель: **[gemma-4-E2B-it-Q4_K_M.gguf](https://huggingface.co/unsloth/gemma-4-E2B-it-GGUF/resolve/main/gemma-4-E2B-it-Q4_K_M.gguf)**, около 3 ГБ.
5. В папке Пульса создайте папку `models` и положите туда скачанный файл. Должно получиться `pulse-main\models\gemma-4-E2B-it-Q4_K_M.gguf`. Имя файла не меняйте.
6. Закройте чёрное окно Пульса и снова откройте `start`.

Пульс запускает модель сам, когда для неё есть работа, обычно раз в полчаса. После первого такого разбора в **Настройки → Приватность** вместо «Локальная модель не установлена» появится её название.

## Шаг 9 (по желанию). Claude

Claude — это ИИ-помощник от компании Anthropic. Пульс может просить его пересказать статью или найти подходящие вакансии и события. Для этого нужна **платная подписка Claude** (Pro или выше). Без неё Пульс работает и так.

1. Скачайте и установите [приложение Claude](https://claude.ai/download), войдите в свой аккаунт.
2. В папке Пульса дважды щёлкните по **`claude_login`**. Откроется чёрное окно, а затем браузер: подтвердите в нём вход.
3. Вернитесь в чёрное окно. Там появится длинный ключ, который начинается с `sk-ant-`. Выделите его мышью целиком и нажмите **Enter**: так ключ скопируется. Затем щёлкните в окне **правой кнопкой мыши**: ключ вставится в строку ввода. Нажмите **Enter**.
4. Окно напишет «Claude отвечает». Его можно закрыть.

Если окно пишет «Claude не найден», откройте приложение Claude, подождите минуту и запустите `claude_login` ещё раз.
5. В Пульсе: **Настройки → Приватность** → отметьте **Просить Claude делать саммари…** → **Сохранить**.

Claude работает через интернет, поэтому Пульс показывает ему **только общедоступное**: новости, посты каналов и открытые группы. Личные переписки и закрытые группы к нему не попадают.

## Пульс на телефоне

Работает, когда телефон и компьютер подключены к одному Wi-Fi, например дома, а Пульс на компьютере запущен.

1. На компьютере: **Настройки → Телефон** → отметьте **Открыть Пульс для телефона в этой сети**.
2. Если Windows спросит про брандмауэр, разрешите доступ **только для частных сетей**.
3. Наведите камеру телефона на появившийся QR-код и откройте ссылку.
4. Чтобы открывать Пульс одним касанием, добавьте страницу на главный экран через меню браузера.

В кафе, в университете и в любом общем Wi-Fi лучше выключать эту галочку: соединение не шифруется.

## Как обновить Пульс

Когда выйдет новая версия:

1. Закройте чёрное окно Пульса. Если включён автозапуск, сначала выключите его в **Настройки → Обновление и уведомления**.
2. Скачайте архив заново по ссылке из шага 2 и распакуйте в новую папку, например `pulse-new`.
3. Из старой папки перенесите в новую:
   - файл `config.json` — это ваши настройки;
   - папку `data` — ваши данные и вход в Telegram;
   - папки `models` и `tools`, если ставили модель.
4. Запустите `start` из новой папки. Если хотите, снова включите автозапуск. Старую папку можно удалить.

## Безопасность

- Папка `data` внутри папки Пульса содержит ваш вход в Telegram. **Никому её не отправляйте**, не выкладывайте в облако и не показывайте. Кто получит её, сможет читать ваш Telegram.
- Если компьютер потерялся или кто-то мог взять эту папку: в Telegram откройте **Настройки → Устройства** и завершите сеанс Пульса.
- Ключи `api_id` и `api_hash` тоже держите при себе.

## Если что-то не работает

| Что происходит | Что сделать |
|---|---|
| Чёрное окно пишет **Python not found** или «python не является внутренней или внешней командой» | Python установлен без галочки PATH. Переустановите его, см. шаг 1 |
| Чёрное окно Пульса пишет «Пульс остановился» | Сфотографируйте то, что написано выше этой строки, и отправьте тому, кто дал вам ссылку |
| Браузер пишет «Не удаётся получить доступ к сайту» | Пульс ещё запускается. Подождите пару секунд и обновите страницу (F5) |
| Страница http://127.0.0.1:8765 не открывается | Проверьте, что чёрное окно Пульса открыто. Если нет, запустите `start` |
| В разделе «Чаты Telegram» пусто | Нажмите **Обновить список**. Если не помогло, запустите `telegram_login` ещё раз |
| Telegram пишет «подождите N секунд» | Telegram ограничивает частые входы. Подождите указанное время и не запускайте вход повторно, иначе ожидание растёт |
| Сайт my.telegram.org пишет ERROR | Выключите VPN или откройте сайт в другом браузере |
| Не появились новости или чаты | Подождите пару минут после первого запуска и нажмите круглую стрелку на странице «Сегодня» |

Чтобы Пульс сам проверил, что не настроено:
1. Откройте папку Пульса, щёлкните по адресной строке, напишите `cmd` и нажмите Enter.
2. В открывшемся окне напишите `python -m pulse doctor` и нажмите Enter.

Строки со значком `!!` показывают, что стоит поправить.
